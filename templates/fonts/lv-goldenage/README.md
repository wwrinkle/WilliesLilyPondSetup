# LV GoldenAge fonts

Music font (`lv-goldenage-*.otf`) and text fonts (`GoldenAgeText.otf`, `GoldenAgeTitle.otf`)
from [OpenLilyPondFonts/lv-goldenage](https://github.com/OpenLilyPondFonts/lv-goldenage)
(commit 8a92fd3), by Abraham Lee.

Licensed under the SIL Open Font License 1.1 (see `OFL.txt`). "LV GoldenAge" is a Reserved Font Name.

`templates/modules/fonts.ly` loads these directly, so they don't need to be installed into LilyPond.
